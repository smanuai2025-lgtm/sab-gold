🔹 المرحلة 1: الهيكل العام للنظام (Skeleton)
--------------------------------------------------

أنشئ Solution احترافي باسم MrGoldenBader يحتوي على:

1) Backend:
- ASP.NET Core 8 Web API
- Clean Architecture:
  - API
  - Application
  - Domain
  - Infrastructure
- إعداد JWT Authentication (نظام مخصص لمالك واحد)
- تكامل SQL Server
- Redis Cache
- SignalR للتحديثات اللحظية
- Logging احترافي

2) AI Services:
- خدمة مستقلة Python FastAPI
- جاهزة لتحليل الأسعار + الأخبار (LSTM + NLP)

3) Frontend:
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- تخطيط Dashboard احترافي

4) DevOps:
- Docker
- docker-compose
- إعداد بيئات (Development / Production)

المطلوب فقط:
- هيكل المجلدات
- ملفات Startup
- Controllers فارغة
- README عربي يشرح التشغيل

لا تنفذ أي منطق أعمال.
